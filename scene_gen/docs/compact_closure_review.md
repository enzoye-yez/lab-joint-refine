# 紧凑布局与恢复改造：两轮工程审查

本记录对应 2026-10-22 的离线工程改造。未启动、恢复正式实验，未调用模型服务，也未探测账户余额或鉴权。旧 NP-002（规程编号）资产、报告和账本不被改写。开发者样例和归档对照不作为 Astra（生成模型）的新实验结果。

## 第一轮：提示、校验约定与异常路径

1. 桌数偏好贯通计划及修复提示，优先 2–3 张桌子；超过时说明实际用途、尺寸及通道/分区依据，未新增按桌数停止的条件。几何占用使用投影并集，重复叠放不会重复计算；未量化的操作留空单独标注。
2. 房间修改增加显式理由和全部环境实例的复核范围。只改房间却不申请相应范围、不给理由、把实例非法缩放，都被拒绝；合法修改沿用原修复和重新检查流程。
3. 机械释放/接合事件引用真实操作接口，不能冒用软件控制或通过声明直接触发释放。无探测实现时标为证据不足。
4. 发现诊断元数据省略可能误放行末端的连接错误。修复为普通资产可保留诊断几何，但末端安装仍校验完整契约；固定运动树冒充可拆件、缺少自由运动能力、错误接合公差等原有反例继续拒绝。原始清单始终保留，正式质量检查仍读取原件。
5. 检查器程序错误继续标为执行错误，同时保留已经取得的检查条目；避免把工程故障交给生成模型当成几何问题。资产补查故障使用独立字段，避免与场景故障账本同名而结构不同。
6. 作者输入列出实际后端能力及资源限制；科学计算库版本加入实现回执。未提供版本的后端不宣称该库可用。

## 第二轮：证据、预算与恢复边界

1. 布局细化只需存在可加载资产，缺件继续保留。按可用资产版本绑定细化尝试；同一输入恢复不补充次数，输入变化不清空累计记录。
2. 依赖就绪清除过期等待关系；暂挂和检查器故障记录具体恢复条件。作者详情交互暂挂每个输入仅有一次精简恢复机会，之前的脚本、反馈和预算保留。
3. 修复了暂挂覆盖作者脚本引用的问题，并检查所有作者循环。非草稿路径收到明确暂挂后立即返回调度层，不在内部重复请求；上下文压缩保留能力限制及恢复指令。
4. 无有效进展的修复候选归档但不覆盖基线；部分改善和布局紧凑性改善分别记录。新缺陷、丢失检查范围或丢失已有粗略接近目标，不因桌数减少而被抹去。
5. 接近性只使用声明的操作接口，装配定位点不再扩大目标集合。无操作接口时明确采用几何中心近似。方向仅在声明时筛查；其他对象包围盒遮挡只用于保守建议，不升级为已确认碰撞。
6. 已发布版本和待修复计划分别显示；文档记录缺件、暂挂和布局指标。历史运行绑定旧实现，不能用新代码直接覆盖恢复；归档回放只读加载模型，另存开发者对照。

## 验证与边界

首轮全量 852 项测试发现 6 项回归：两个测试替身缺少实现绑定、一个执行错误状态回归、三个末端契约回归。均已修复。随后 117 项针对性测试通过；阶段全量 857 项测试全部通过（717.142 秒），核对了测试前后源码、测试文件及依赖版本不变。结果和源码/依赖摘要保存在 `.cache/compact_closure_20261022/`（工程验证缓存）中。

覆盖包括真实末端装配反例、悬空/承托、槽位和尺寸、过期证据、路径越界、预算中止、未知请求恢复、上下文分页、局部缺件发布，以及本次新增的房间授权范围、机械事件、目标筛选和暂挂源文件保留。

仍未认证完整导航、逆运动学、双臂协同轨迹、机械事件的实际执行或维护空间。离线测试只能证明覆盖范围内的行为；模型能否稳定自主生成更紧凑且质量合格的场景，须在余额恢复、用户授权后另开正式运行。

## 真实归档回放发现的追加性能修复

首轮真实场景回放在承托检查阶段长时间消耗。对本次离线进程做 10 秒只读采样：499 个样本中，478 个处于场景承托检查调用内；其中 295 个停在逐对包围盒排除判断。该证据定位到了实际热点，不能从总耗时推断为模型或网络问题。

修复将支撑物与被支撑物的逐对包围盒循环改为一次建立被支撑几何的 x 轴索引，再按窗口向量筛选；恢复原对象顺序后送入原距离量测。量测预算、公差、承托法向判断、组件连接链及未知结果处理均不变。新增随机包围盒、负坐标、边界相切、地面和预算前缀的等价性回归。78 项针对性测试通过。一次开发者合成基准中，501 个支撑候选与 1000 个对象几何得到完全相同的 1056 个有序配对；筛选耗时从 1.2458 秒降为 0.0148 秒。此数据不是正式场景端到端性能结论。

旧离线进程已停止，采样和未完成状态保留；正式运行未动。追加修复使实现摘要发生变化，因此之前的 857 项通过回执仅保留为阶段证据，最终交付以追加修复后的全量回执为准。

追加性能修复后的最终全量测试：859 项全部通过，659.665 秒；源码、测试文件及依赖版本与测试开始绑定一致。回执位于 `.cache/compact_closure_20261022/indexed-verification.json`。


## 归档对照中的原生进程异常

原五桌归档在当前实现下完成完整静态检查及渲染：286 项通过、49 项失败、71 项证据不足、3 项按静态范围跳过；含加载共 1870.48 秒。该耗时发生在本机工程验证期间，不作为生产环境性能承诺。

随后三桌开发者候选在承托量测中异常退出。Windows（操作系统）事件 1000/1001 记录 2026-10-22 19:06:21 的 Python（运行时）访问冲突 `0xc0000005`，故障模块为 `python311.dll`（运行时动态链接库）。没有 Python 层异常回执，不能将其归因为模型、鉴权、几何不合格或已证实的框架代码缺陷，也不能因单元测试通过而忽略它。

保留系统事件、周期堆栈采样和未完成日志；在独立进程中仅补跑候选检查一次，取消本次临时周期堆栈采样，检查规则和公差不变，并记录每个实例的承托检查起止。取消采样是排查变量，不代表已证明采样是崩溃原因。补跑前核对原归档摘要与其正式发布回执一致。
