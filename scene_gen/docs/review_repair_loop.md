# 审查、补查与定向修复闭环优化

后续更新：本记录中的局部停止与恢复规则已由[持续推进优化](continuation_policy.md)调整；本页验证数字是当时版本的历史记录。

日期：2026-10-20。工程实现与离线验证记录；没有运行正式模型实验，没有改写原五例资产、检查报告或调用账本。

## 设计与实现

沿用现有审查器、检查能力注册表、证据会话、修复历史和场景归档，不新增通用代理框架或第二套问题数据库。修复任务由当前检查事实派生；任务携带输入版本、检查编号、涉及实例、具体组件/碰撞对、原证据记录位置、共享资产实例和复查要求。

处理顺序：先发布可加载诊断场景，再检查和审查；格式错误只修正响应，证据不足请求适用的只读能力，已定位的确认缺陷转入定向修复。修改后重查资产、依赖和完整场景，比较原问题与新问题，然后选择候选。未知、工具故障与已确认缺陷始终分别保存。

| 环节 | 本轮改进 | 保留的约束 |
|---|---|---|
| 审查约定 | 精确反馈缺失、重复、未知事项编号及字段；合法答案保留，仅补缺失或错误答案；超过16项按批处理后合并校验 | 重复冲突答案不保留；所有合并结果仍经过完整校验；不自动填入通过 |
| 格式恢复 | 保存尝试次数、纠正上下文与完成响应；初审和补查后复审均受3次格式尝试限制 | 中断消耗的尝试不回填；格式失败不能冒充几何问题 |
| 补查选择 | 按实际清单校验构型、对象和有界关节；普通单构型不再被要求引用不存在的构型表 | 固定公差不变；不存在的名称在工作进程启动前拒绝 |
| 已有证据 | 同一输入版本成功动作返回已有结果，混合批次仅执行新动作；重复复用而无新动作时停止 | 不完整或失败动作不能作为成功缓存；视图不能清除无关数值缺口 |
| 修复调度 | 有可定位的确认缺陷时优先修复，其他未知保留；独立局部执行故障只阻断受影响对象 | 程序故障、全局故障和无法可靠分区的故障仍阻塞；共享资产对象不能绕过故障限制 |
| 修复能力不足 | 模型可明确返回缺证据、无受支持修复方式或契约冲突；保存阻塞后恢复不重复请求同一计划 | 不因空方案放宽权限，也不通过反复调用掩盖能力缺口 |
| 候选选择 | 相同检查编号比较解决项、残留项、新增缺陷、碰撞深度和规格偏差；覆盖丢失、退化或有得有失时保留基线 | 消失、跳过和未知不等于解决；不靠减少失败总数证明改善 |
| 发布与恢复 | 静态候选退化或装配失败时恢复归档引用；保留失败候选、调用、阶段和轮次；结果提供证据与修复进展摘要 | 恢复前验证基线归档摘要；不倒退预算，不覆盖原资产 |

每批审查继续携带所需图片及上下文，不以删除图片降低成本。分批减少单次回答遗漏风险，但会增加固定审查开销；仍受原模型调用及令牌账本约束，尚未证实正式实验总成本下降。

## 能力范围

本轮接通并验证的是现有数值检查与修复调度的协作：整体放置与承托、内部实体连接、当前姿态的几何干涉、原固定尺寸规格，以及视图/指定几何对/承托/周边/安装/材料检查等既有能力。框架负责确定修改权限、证据版本和验收条件；具体资产几何仍由所选生成模型给出。

没有新增通用几何求解器。局部任务会指明组件和证据，但不保证模型能产出正确修复。复杂槽形、柔性接触、连续插入路径、动力学、受力和机器人完整操作仍不属于本轮证明范围。槽位测试验证当前配合姿态存在实体封堵及移除封堵后的变化，不代表整条插入路径可行。

自动保留基线及候选比较主要接入静态流程；不据此声称完整操作流程具备同等回归保护。对未量化的视觉缺陷，保留审查发现与实例范围，没有声称具备通用视觉严重度排序。候选取舍采用保守规则：修好一个问题却引入另一个问题时不自动替换基线，可能停止在尚不能自动跨越的中间状态。

无改善但无新增问题、无证据退化的候选可以保留，但记录为无效修复；相同输入与问题上的相同修复不能无限重复。所有重试还受现有全局预算约束。无法保证任意断电/磁盘故障下恰好调用一次；结果未知的模型请求沿用原账本保护，不声称退款。

## 两轮审查

第一轮：提示、校验约定与异常路径。

- 修正单构型清单与补查提示不一致的问题；补充真实构型、对象、关节预检。
- 将事项错误定位到编号与字段，保留独立合法项；重复冲突项必须重新回答。
- 核查分批合并仍执行完整约定校验；未验证事项不被补成通过。
- 将初审及补查后复审的格式耗尽都从几何补查流程分离。
- 增加明确的修复能力阻塞响应，恢复同一阻塞不再消耗模型调用。

第二轮：证据、预算、候选退化与恢复边界。

- 证据会话绑定输入、规程、待验证事项、构型/布局、固定契约和实现身份；修改后旧证据失效。
- 成功缓存复用与失败重试分开；不完整动作不能充当成功结果，临时故障与程序错误区分。
- 候选比较不能把检查消失、变为未知、扩大覆盖缺口或同一碰撞加深当成改善。
- 复查已提交而候选选择中断时，恢复先完成选择，即使场景轮次已耗尽。
- 装配失败的修复候选同样保留旧场景；只恢复引用，失败归档、阶段、轮次和模型费用记录都保留。
- 共享资产与故障对象重叠时停止修复，不以实例过滤掩盖共享几何影响。
