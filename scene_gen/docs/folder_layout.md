# 目录职责与保留规则

整理日期：2026-10-24。本轮只增加导航，不迁移现有运行路径。

| 位置 | 职责 | 保留规则 |
|---|---|---|
| ../src | 源码 | 当前工程，不清理 |
| ../config | 当前、可选及冻结实验配置 | 按调用入口辨认，不能按相似名称合并 |
| ../scripts | 工程与运行工具 | 保留现有路径 |
| ../tests | 工程测试 | 保留样例来源 |
| ../data | 机器人模型、网格与来源 | 必需资源，不当缓存删除 |
| ../runs | 实验、接续副本与账本 | 保留原始目录及状态，不按名称判断成功 |
| ../exports | 场景交付包 | 查看与分享入口，不替代原始记录 |
| ../reports | 已有历史报告与交付 | 保留原路径，通过索引访问 |
| ../evidence | 本轮及后续整理证据 | 保存整理前文件与验证结果 |
| ../.cache | 缓存与尚未分类的历史证据 | 禁止整体清空；含检查点、启动记录、构建来源 |
| ../.venv | 本地运行环境 | 启动脚本依赖，禁止直接移动 |

父目录的 selected50_protocols（原始规程集）仍是批次默认输入位置。C 盘登记的工作副本属于版本管理工作区，不能作为重复文件直接删除。

已有历史资料尚未迁移；新目录规则不表示程序输出路径已经改变。后续迁移必须先核对消费者、保存快照，再更新引用并验证恢复。
