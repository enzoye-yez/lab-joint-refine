| 审查内容 | 发现及处理 | 验证依据 |
|---|---|---|
| 固定桌与移动多桌共存 | 移动环境单独扩展现有规划/修复提示；旧版保持原约定。实际装配使用逐桌尺寸，参考桌尺寸不覆盖计划 | 新移动流程测试、旧场景回归 |
| 多桌坐标 | 世界摆放与局部切槽分开；实际几何转换到桌坐标后再量测，避免对世界包围盒重复旋转扩大误差 | 旋转长条资产、局部切槽测试 |
| 支撑与关联移动 | 桌子变换携带未显式重定位的实例；支撑后代按原相对姿态更新；跨桌改派不缩放资产 | 旋转、跨桌、支撑链与越权测试 |
| 删除工作台 | 原处理遗漏了重新安置到地面的合法情况，已允许显式落地并清除桌编号 | 删除桌子后落地测试 |
| 可加载与质量区分 | 部分场景允许没有末端，完整场景仍执行原约束；缺件不能改为通过 | 缺末端测试、篡改元数据回归 |
| 桌外悬挑占道 | 仅把落地资产纳入通道障碍会遗漏桌面资产伸出的部分，已纳入所有非机器人实例的几何投影 | 悬挑几何阻挡底盘测试 |
| 模型来源 | 采用公开移动平台规格与现有机械臂模型；立柱、质量和运动简化逐项记录，不声称复现全部硬件 | 配置、装配清单、场景说明核对 |
| 大场景显示 | 房间边界扩大后默认相机使主体过小，改为以实际占用区域确定初始视角 | 两个历史场景重新渲染、人工查看 |

## 尚未验证与限制

- 这轮没有调用正式模型，不能断言新模型实验会收敛，或质量已经优于旧批次。
- 通道和距离只提供粗略布局建议，没有验证逆运动学、机械臂绕障、操作朝向、完整操作轨迹。
- 活动关节仅做运动学抽查；驱动、闭链约束满足、碰撞自由开合和轮地动力学未认证。
- 历史重放没有重新执行全量碰撞、承托及视觉验收，不能把重放成功算作旧场景质量通过。
- 场景说明可在规划失败时交付；如果没有合法计划或资产不能加载，无法诚实保证存在完整模型。
- MuJoCo（物理仿真引擎）的资源附加路径仍会输出资源字典提示；本次公开机械臂及两份历史模型导出后重新加载成功。未将该提示当作所有未来模型资源均正确的证明。
